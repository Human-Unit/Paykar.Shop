## Coverage interpretation

The audit combines source reads, route DOM/geometry inspection, screenshots and visual review of representative evidence. This directory is a baseline, not a claim that every route/control/error state passed acceptance. Most route screenshots show the top viewport; lower anchor details/network/category/editorial sections have separate element captures. No screenshot should be used to infer untested checkout, provider, storage or map gesture success.
